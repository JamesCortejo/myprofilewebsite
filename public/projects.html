ResQMesh Website

Website + Admin Dashboard

Emergency response platform web experience

Website
The ResQMesh website includes both the public landing site and the secured admin command-center. The landing page introduces the system, provides information for users, supports registration, contact, password reset, and app downloads, while the admin dashboard manages civilian accounts, rescuers, rescue teams, mesh devices, distress deployments, reports, online department chats, and operational monitoring.

Landing Website - Admin Dashboard - Operational Monitoring

Featured Project

ResQMesh Mobile App

Mobile App

Emergency coordination for civilians and rescuers

Mobile App
The ResQMesh mobile app is used by civilians and rescuers in both online and mesh/offline modes. It supports distress activation, cloud and mesh chat, voice messages, active maps, rescue routes, notifications, rescuer location sharing, and emergency coordination even when internet access is limited. I developed this app in Expo using TypeScript.

Expo - TypeScript - Mobile App - Mesh / Offline Mode - Emergency Coordination
