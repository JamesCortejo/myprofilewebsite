Mobile App
The ResQMesh mobile app is used by civilians and rescuers in both online and mesh/offline modes. Featured Project

ResQMesh Device

Hardware + Mesh Node

Portable emergency communication device

The ResQMesh Communication Device is a portable emergency communication node for situations where cellular networks, internet access, or regular communication infrastructure are unavailable. It works as the physical mesh node that connects the mobile app with other ResQMesh devices.

It runs on an Orange Pi Zero 3 with a LoRa E22-400T30D-V2 radio module for long-range communication, GPS for location tracking, and power monitoring for battery awareness.

Key Components
  • Orange Pi Zero 3 - main controller
  • EBYTE E22-400T30D-V2 LoRa module - long-range mesh communication
  • NEO-6M GPS module - location tracking
  • INA219 power monitor - voltage and current monitoring
  • 3S LG MJ1 18650 battery pack with BMS - portable rechargeable power

The device provides the hardware layer for offline messaging, distress coordination, GPS sharing, and emergency communication between mesh nodes.
